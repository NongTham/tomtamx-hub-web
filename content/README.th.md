# ตั้งค่าเว็บไซต์ TomTamX

เว็บไซต์ดึงรายการสคริปต์แบบสดจาก Rscripts Public API ทุกครั้งที่เปิดหน้า และรีเฟรชซ้ำทุก 60 วินาที จึงไม่มี `games.json` หรือรายการสคริปต์ที่คัดลอกเก็บไว้ในโปรเจกต์

ข้อมูลที่ดึงมาเฉพาะรายการที่ตรงกับบัญชี TomTamX และรหัสผู้เผยแพร่ที่กำหนดไว้ใน `src/api/rscripts.js` เท่านั้น แต่ละรายการใช้ชื่อ คำอธิบาย ลิงก์ต้นทาง และ raw script จาก API โดยตรง แล้วสร้าง loader ในรูปแบบ `loadstring(game:HttpGet(rawScript))()` ให้คัดลอกได้

ไฟล์ที่แก้เองได้ยังมีสองไฟล์:

- `content/site.json` สำหรับชื่อเว็บ โลโก้ สี และข้อความหน้าเว็บ
- `content/suite.json` สำหรับ Master Loader และลิงก์ Discord/GitHub

หาก Rscripts ไม่ตอบกลับ หน้าเว็บจะแสดงปุ่ม Try again แทนการใช้ข้อมูลเก่า
